Assessment — WordPress Developer (Elementor)
Assessment ini bertujuan untuk menguji pemahaman dasar kandidat mengenai WordPress dan Elementor.
Pilihan Ganda
1. Fungsi utama Elementor pada WordPress adalah?
•	A. Mengelola database
•	B. Membuat desain website secara visual
•	C. Mengamankan server
•	D. Mengatur domain
Kunci Jawaban: B
2. Plugin yang umum digunakan untuk membuat toko online di WordPress adalah?
•	A. Yoast SEO
•	B. Elementor
•	C. WooCommerce
•	D. Contact Form 7
Kunci Jawaban: C
3. Apa tujuan website dibuat responsive?
•	A. Agar loading lebih lambat
•	B. Agar website hanya tampil di desktop
•	C. Agar website dapat menyesuaikan berbagai ukuran layar
•	D. Agar warna website berubah otomatis
Kunci Jawaban: C
4. Bahasa dasar yang digunakan untuk styling website adalah?
•	A. PHP
•	B. CSS
•	C. SQL
•	D. Python
Kunci Jawaban: B
5. Apa fungsi plugin pada WordPress?
•	A. Menambah fitur website
•	B. Menghapus hosting
•	C. Mengatur monitor
•	D. Mengganti domain otomatis
Kunci Jawaban: A
6. Elementor termasuk jenis tools?
•	A. Database Manager
•	B. Visual Page Builder
•	C. Browser
•	D. Framework Backend
Kunci Jawaban: B
7. Apa yang biasanya mempengaruhi kecepatan website?
•	A. Ukuran gambar terlalu besar
•	B. Nama website
•	C. Warna tombol
•	D. Jumlah menu sedikit
Kunci Jawaban: A
8. Fungsi section/container di Elementor adalah?
•	A. Menyimpan database
•	B. Mengatur layout halaman
•	C. Menghapus plugin
•	D. Membuat hosting
Kunci Jawaban: B
9. Apa tujuan maintenance website?
•	A. Membuat website error
•	B. Menjaga performa dan keamanan website
•	C. Menghapus semua halaman
•	D. Mengurangi traffic website
Kunci Jawaban: B
10. Jika tampilan website berantakan di HP, maka yang perlu diperiksa adalah?
•	A. Responsive setting
•	B. Nama domain
•	C. Username admin
•	D. Email website
Kunci Jawaban: A
Mini Project

Buat 1 halaman landing page menggunakan WordPress & Elementor untuk sebuah Perusahaan konstruksi

Ketentuan:
• Responsive desktop & mobile
• Minimal terdiri dari:
  - Hero Section
  - Tentang Kami
  - Layanan
  - Portfolio/Testimoni
  - CTA / Contact Section
• Menggunakan design yang rapi dan modern
• Wajib menggunakan Elementor
• Optimasi basic spacing, typography, dan layout

Pengumpulan:
• Link website/demo
• Screenshot tampilan desktop & mobile
• Waktu pengerjaan maksimal 2 hari
